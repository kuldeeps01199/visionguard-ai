# VisionGuard AI 🛡️
**An easy-to-use web app that detects whether an image is Real or AI-Generated.**

Welcome to VisionGuard AI! This tool helps you upload an image and quickly tells you if it was taken by a camera or generated by Artificial Intelligence. 

## 🌟 What does it do?
- **Upload Images:** Easily drag and drop an image into the website.
- **Fast Analysis:** The system instantly analyzes the picture and gives you a result.
- **Modern Design:** Enjoy a beautiful, dark-themed website that looks great and is simple to use.

---

## 🛠️ How to run this on your computer

Follow these simple steps to get the app running on your own machine.

### Step 1: Get the Code
Download this folder to your computer, or open your terminal (Command Prompt) and type:
```bash
git clone https://github.com/YOUR-USERNAME/visionguard-ai.git
cd visionguard-ai
```

### Step 2: Install Required Software
Make sure you have **Python** installed. Then, install the required packages by running:
```bash
pip install -r requirements.txt
```

### Step 3: Get the AI Model Ready
To use the website, it needs a "brain" (a trained model) to identify images. You have two options:

**Option A: The Quick Way (For Testing the Website)**
Run this command to create a temporary dummy model so you can instantly see how the website looks:
```bash
python generate_dummy_model.py
```

**Option B: The Real Way (For Actual Image Detection)**
1. Download the [CIFAKE Dataset from Kaggle](https://www.kaggle.com/datasets/birdy654/cifake-real-and-ai-generated-synthetic-images).
2. Extract the downloaded files into a folder named `dataset` inside this project.
3. Run the training process (this will take a few hours):
   ```bash
   python train.py
   ```

### Step 4: Start the Website!
Once you have done either Option A or Option B, you can start the website by running:
```bash
python app.py
```
Now, open your web browser and go to **`http://localhost:5000`** to use the app!

## 🌍 How to put it on the Internet
If you want to share your website with others, you can host it for free using Render:
1. Make an account on [Render.com](https://render.com/).
2. Click **New +** and choose **Web Service**.
3. Connect your GitHub account and select this project.
4. Set the Build Command to: `pip install -r requirements.txt`
5. Set the Start Command to: `gunicorn app:app`
6. Click **Deploy** and wait for it to go live!
