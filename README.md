# VisionGuard AI 🛡️
**An easy-to-use web app that detects whether an image is Real or AI-Generated.**

Welcome to VisionGuard AI! This tool helps you upload an image and quickly tells you if it was taken by a camera or generated by Artificial Intelligence. 

## 🌟 Features
- **Upload Images:** Easily drag and drop an image into the website.
- **Fast Analysis:** Powered by an ultra-fast ONNX model for instant results.
- **Modern Design:** Enjoy a beautiful, dark-themed website that looks great and is simple to use.

---

## 🛠️ How to Run Locally

1. **Get the Code:**
   ```bash
   git clone https://github.com/YOUR-USERNAME/visionguard-ai.git
   cd visionguard-ai
   ```

2. **Install Requirements:**
   Make sure Python is installed, then run:
   ```bash
   pip install -r requirements.txt
   ```

3. **Start the App:**
   ```bash
   python app.py
   ```
   Open your browser and go to `http://localhost:5000`.

---

## 🌍 How to Deploy (Free on Render)

This app uses an optimized ONNX backend, meaning it requires very little memory and easily fits on free hosting platforms like Render.

1. Make a free account on [Render.com](https://render.com/).
2. Click **New +** and choose **Web Service**.
3. Connect your GitHub account and select this project.
4. Set the Build Command: `pip install -r requirements.txt`
5. Set the Start Command: `gunicorn app:app`
6. Click **Deploy** and wait for it to go live!
